## できたもの

1024×1024 の1枚の中に、**日本語の見出し・部位ラベル・引き出し線・学名**まで入った図鑑ページを作れた。
テキストはすべて画像として描かれてるので、あとから画像編集ソフトで文字を足す必要はない。

![横から見たオスのカブトムシに頭角・胸角・上翅・脚のラベルを付けた図鑑風イラスト](photo:98e3e1bddf56a467)

ポイントは MOSS-Image の **B-BOX レイアウト**。プロンプトを文章で書く代わりに、
「この箱にはタイトル文字」「この箱には虫」「この箱にはラベル」と矩形で指示する仕組み。
これがあると日本語の文字がほぼ崩れずに出る。

## 生成時間（実測）

| レイアウト | step | 1枚目 | 2枚目以降 |
|---|---|---|---|
| v1（要素9個） | 3 | 163.4秒 | — |
| v2 / v2b（要素9個） | 3 | 91.2〜93.2秒 | — |
| v4b（雌雄比較） | 3 | 93.2秒 | — |
| v5（生活環） | 3 | 98.2秒 | — |
| v6b（夜の樹液） | 8 | 119.2秒 | — |
| v7b（体のつくり） | 8 | 121.2秒 | — |
| v7 同一プロンプト・seed違い | 3 | 92.2秒 | **19.0秒** |

初回はエンコード込み。同じレイアウト文字列で seed だけ変えると conditioning がキャッシュされて **19秒**まで落ちる。
文字を1文字でも変えるとキャッシュが外れて90秒台に戻る。

ラベルを1枚に4〜6個も入れると、v1 のように要素数が増えて 160秒台まで伸びることがある。
要素を絞った v2b が同じ情報量で90秒台なので、**箱は増やしすぎない方が速い**。

## B-BOX の書き方

レイアウトは JSON にして、そのまま `CLIPTextEncode` の positive に流し込む。
座標は**画像中心を原点**にした `[y1, x1, y2, x2]` の順で、`bbox_format: "yxyx"`、
`bbox_coord_space: "abs_centralized"` を指定する。

```python
W = H = 1024

def centered(x1, y1, x2, y2):
    return [y1 - H // 2, x1 - W // 2, y2 - H // 2, x2 - W // 2]

def text(caption, txt, box):
    return {"label": "text", "caption": caption, "text": txt, "bbox": centered(*box)}

def obj(caption, box, label="object"):
    return {"label": label, "caption": caption, "bbox": centered(*box)}

layout = {
    "summary": {
        "caption": "vintage Japanese natural history encyclopedia infographic, "
                   "flat woodcut illustrations, aged cream paper background, "
                   "fine ink linework, muted earth tones, scientific diagram style",
        "meta": ["infographic", "illustration"],
    },
    "items": [
        obj("aged cream paper background with a thin double-line border", (0, 0, 1024, 1024)),
        text("large bold Japanese title text reading カブトムシ",
             "カブトムシ", (80, 50, 944, 190)),
        obj("large detailed male Japanese rhinoceros beetle seen from the side, "
            "wings fully closed, glossy dark brown elytra, long curved forked head horn",
            (150, 300, 880, 780), "character"),
        text("label text reading 頭角", "頭角", (700, 270, 980, 350)),
        text("label text reading 胸角", "胸角", (380, 330, 620, 410)),
        text("label text reading 上翅", "上翅", (770, 520, 990, 600)),
        text("label text reading 脚", "脚", (40, 600, 240, 680)),
        text("caption text reading 学名 Trypoxylus dichotomus",
             "学名 Trypoxylus dichotomus", (80, 810, 620, 880)),
    ],
    "bbox_coord_space": "abs_centralized",
    "bbox_format": "yxyx",
}

prompt = json.dumps(layout, ensure_ascii=False, separators=(",", ":"))
```

`label` は `text` / `character` / `object` の3種類。`text` には `text` フィールドが必須で、
ここに書いた文字列がそのまま描かれる。

### 文字を崩さないコツ

- `caption` に **"large bold Japanese title text reading ○○"** のように英語で役割を書く
- 文字ボックスは高さ **120px 以上**、幅は文字数 × 90px くらい取る
- ネガティブに `misspelled text` と `gibberish text` を入れる
- 同じ文字列を2か所に書くと**重複して描画される**（v6 の初期版で「カブトムシの主要な餌場」が2回出た）

## カブトムシという昆虫

ここからは図鑑の中身。画像と合わせて読めるように、説明をできるだけ詳しく書いておく。

### 分類と名前

| 項目 | 内容 |
|---|---|
| 和名 | カブトムシ |
| 学名 | *Trypoxylus dichotomus*（旧 *Allomyrina dichotoma*） |
| 英名 | Japanese rhinoceros beetle |
| 目 | コウチュウ目（甲虫目 Coleoptera） |
| 科 | コガネムシ科 Scarabaeidae |
| 亜科 | カブトムシ亜科 Dynastinae |
| 属 | *Trypoxylus*（ヤマトカブトムシ属） |

日本に分布するカブトムシ亜科はこの1種だけ。つまり日本のカブトムシは
**1属1種**で、近縁の大型種に囲まれた大陸のカブトムシ類とは事情が違う。
台湾・中国・朝鮮半島・インドシナ半島にも分布し、地域ごとに亜種が分けられている。

名前の由来は、オスの頭部の角が兜の前立てに似ていることから。
漢字では「甲虫」「兜虫」と書き、古い文献では「さいかちむし」とも呼ばれていた
（サイカチの樹液に集まるところから）。

### 体のつくり

![真上から見たオスの体のつくり図](photo:f9f8938b3c85f62f)

昆虫の標準どおり、体は**頭部・胸部・腹部**の三部に分かれる。硬い外骨格（キチン質）が全身を覆い、
脱皮のたびに殻を作り直す。

- **頭角**：オスだけにある大きな角。根本からゆるやかに湾曲し、先端が二股に分かれる。
  個体によっては途中に小さな突起が1〜2本出る。角の長さは体長の半分近くに達することもある。
- **胸角**：前胸背板の前端から前方へ伸びる、頭角より短くまっすぐな角。
  オスのみ。頭角と胸角で樹木の枝を挟み、ライバルを押し出すのに使う。
- **前胸背板**：胸部の背面を覆う硬い板。光沢のある暗褐色〜黒色で、細かい点刻がある。
- **小楯板**：前胸背板と上翅の間にある小さな三角形の板。
- **上翅（鞘翅）**：硬い前翅が背中を覆う。飛ぶときはこの鞘を開き、
  下に畳まれている薄い後翅を広げる。静止時は鞘を閉じて隙間なく体を保護する。
- **脚**：6本。前脚・中脚・後脚の区別があり、先端の爪で樹皮にしがみつく。
  オスの前脚はメスより太く、角の内側の突起も発達する。
- **腹部**：上翅の下に隠れる。気門（呼吸孔）が並び、ここから空気を取り入れる。

![オスとメスの見分け方](photo:f00931db2f0bc005)

### オスとメスの違い

| | オス | メス |
|---|---|---|
| 角 | 頭角＋胸角の2本、長い | ほとんどない（小さな突起のみ） |
| 体長 | 40〜55mm（大型は80mm超えも） | 35〜45mm |
| 前脚 | 太く、内側に突起 | 細い |
| 腹面 | やや毛深い | 比較的平滑 |

角の大きさは栄養状態に左右される。幼虫期に十分な腐葉土を食べた個体ほど角が長くなる。
そのため「角の長さで強さがわかる」と言われるが、実際の闘争では
**体の大きさと脚の力**の方が効くという研究もある。

### 生活環

![カブトムシの一生](photo:c1b165d42fa45af7)

| 段階 | 期間 | 内容 |
|---|---|---|
| 卵 | 約10日 | 腐葉土の中に1個ずつ産む。直径2〜3mmの楕円形。 |
| 幼虫 | 約10か月 | 三齢を経て成長。終齢で体長10cm近くになる。腐葉土・腐植土を食べる。 |
| 蛹 | 約3週間 | 土の中で蛹室を作り、その中で蛹になる。角の形はすでにできている。 |
| 成虫 | 2〜3か月 | 蛹室を破って地上へ。6〜8月に活動し、秋に死ぬ。 |

卵から成虫まで**約1年**。成虫として地上で過ごすのは1年のうち3か月ほどしかない。
幼虫は頭を下に向けて土の中を移動し、刺激を受けると体をC字に丸める。

### 成虫の生態

![夜のクヌギの幹に樹液を求めて集まるカブトムシ](photo:87738858fa3fa6fc)

- **食性**：クヌギ・コナラ・ミズナラなどの樹液。発酵した樹液の糖分と酵母を摂る。
  自分で樹皮を傷つけて樹液を出すことはできず、カミキリムシやボクトウガの幼虫が
  開けた穴に依存している。スイカやバナナに集まるのも糖分と発酵臭のため。
- **活動時間**：夜行性。日没後から活動を始め、夜明け前には樹皮の隙間や落ち葉の下に隠れる。
  街灯や街路樹にも飛来し、灯火に集まる**正の光走性**を示す。
- **飛翔**：重い体を後翅だけで飛ばす。離陸前に鞘翅を開いて後翅を温める動作をする。
  飛距離は数百m程度で、直線的に飛ぶのは苦手。
- **繁殖行動**：オス同士が角と脚を使って押し合い、樹液場をめぐって争う。
  メスは産卵に適した腐葉土を探して地表を歩き回る。
- **天敵**：カラス・イノシシ・アナグマ・モグラなど。幼虫はケラやハリガネムシに狙われる。
- **寿命**：成虫は2〜3か月。飼育下では4か月程度まで生きることもある。

### 分布と生息環境

北海道南部から九州まで、日本のほぼ全域に分布する。
ただし**北海道北部・東部には自然分布しない**（人為移入の記録あり）。
平地から低山地の落葉広葉樹林、とくにクヌギ・コナラの二次林（里山）を好む。
都市部の公園や学校の植栽にも定着しており、街中でも普通に見られる。

幼虫は腐葉土の厚い層を必要とするため、**落ち葉が溜まる里山の土壌**が繁殖の鍵になる。
近年は里山の管理放棄による腐葉土の減少で、個体数が減っている地域もある。

### 人との関わり

- **昆虫食**：長野県など一部の地域では、幼虫を佃煮や炒め物にして食べる習慣があった。
- **文化**：夏休みの昆虫採集の定番。江戸時代から「さいかちむし」として文献に登場する。
- **飼育**：腐葉土を敷いたケースで幼虫から飼える。成虫は糖分（昆虫ゼリー）を与える。
- **注意**：外来種問題の観点から、地域外の個体を放虫しないことが望ましいとされる。

## 作ってみて踏んだ罠

1. **文字ボックスが狭いと崩れる**。高さ120px未満だと「カブトムシ」の「シ」が欠けることがあった。
2. **同じ文字を2か所のボックスに書くと二重に出る**。caption と text を別々に渡していたのが原因。
3. **ラベルの位置は指定どおりにならないことがある**。`上翅` を翅の右端に置いたつもりが、
   翅が開いた絵になったので矢印が虚空を指した。**絵の状態（翅を閉じた）を caption で明示する**のが効いた。
4. **要素を増やすと遅くなる**。v1 は9要素で163秒、v2b も9要素だが90秒台。
   要素の「中身の複雑さ」より、caption の長さがエンコード時間に効いている。
5. **step を上げても日本語はあまり良くならない**。3step と 8step で文字の正確さに差はほぼなく、
   絵の密度が上がるだけだった。文字狙いなら 3step で十分。

## 再現するには

上の JSON をそのまま `CLIPTextEncode` の positive に入れれば同じ絵が出る。
乱数は seed 31415 で固定してある。レイアウトのバリエーションは
生成スクリプトに v1〜v7b まで函数として残してあるので、
箱の座標を書き換えれば別の図鑑ページに流用できる。

ネガティブはこれ。

```
worst quality, low quality, bad anatomy, extra limbs, watermark,
jpeg artifact, blurry, bad proportions, misspelled text, gibberish text
```

**`nsfw` は絶対に入れない。** MOSS-Image はネガティブに nsfw があると
露骨なプロンプトでも何も描かなくなる（ComfyUI 公式テンプレートに入っているので注意）。
