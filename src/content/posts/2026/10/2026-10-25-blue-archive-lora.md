Civitai の MOSS-Image 専用 Blue Archive LoRA を使って、10人のキャラを指定して生成した。RTX 2080 SUPER 8GB で30枚。

**キャラ名だけでは設定が混ざる。** 髪色・瞳・ハロー・制服まで書いて、初めて「そのキャラ」になる。

## LoRA

| 項目 | 内容 |
|---|---|
| 名前 | 【MOSS Image】Blue Archive style |
| 作者 | wiehhg_37 |
| URL | https://civitai.com/models/3010579 |
| ベース | MOSS Image |
| バージョン | v0.9 |
| 公開 | 2026-10-19 |
| サイズ | 129,017,232 bytes (123MB) |
| SHA256 | `ACB4C62B...DC35` |
| 学習 | 296枚 / 10,000 steps / dim 32 |

**ベースが `MOSS Image` であることを必ず確認する。** Civitai にある Blue Archive LoRA の多くは Illustrious・Pony・Anima ベースで、MOSS では効果が出ない。

| RAM | 32GB |

## 生成設定

| 項目 | 値 |
|---|---|
| diffusion | MOSS-Image-SFT Q4_K_M GGUF |
| encoder | Qwen3.5-9B W4A8（CPU） |
| 蒸留LoRA | moss_image_sft_3step_v1.0（1.0） |
| スタイルLoRA | blue-archive-style-v0.9（**0.9**） |
| attention | comfy kitchen attention（INT8） |
| 解像度 | 1024×1024 |
| step / cfg | 3 / 1.0 |
| sampler | er_sde / simple |

## 生成時間

| 条件 | 時間 |
|---|---|
| 1枚目（LoRAロード込み） | 156.4秒 |
| 同一プロンプト2枚目以降 | 18〜19秒 |
| プロンプト変更時 | 91〜94秒 |

**30枚で合計 1362.3秒（22分42秒）、平均 45.4秒。**

同一キャラで seed を3つ振ると2枚目以降は19秒。キャラを変えるとエンコードが走って91秒に戻る。

## キャラ名だけでは足りない

最初に `aris (blue archive)` とだけ書いたら、**ピンク髪の女の子が出た**。アリスは黒髪なので間違い。

LoRA はスタイルを学習したもので、キャラ設定までは持っていない。**髪色・髪型・瞳・ハロー・制服を明示する必要がある。**

| キャラ | 間違えやすい点 |
|---|---|
| アリス | ピンクではなく**青紫がかった黒髪**。ヘッドホンではなく**カチューシャ** |
| ユウカ | ツインテールではなく**ツーサイドアップ**（上部だけ結ぶ） |
| ホシノ | **オッドアイ**（右が黄・左が青） |
| コハル | 猫耳ではなく**頭部の翼** |
| ミカ | 腰から**白い羽の翼** |
| ヒナ | **角とコウモリの翼** |
| セリカ | **猫耳あり**（これは合ってた） |
| アヤネ | **尖った耳**と赤縁の眼鏡 |
